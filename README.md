## 📌 Sobre

**PYTHON-STUDY** é um repositório criado para documentar minha jornada de aprendizado e evolução em **Python**, através de uma trilha prática de **100 dias de programação**.

O objetivo é desenvolver não apenas conhecimento sobre a linguagem, mas principalmente **lógica de programação, capacidade de resolução de problemas e experiência prática no desenvolvimento de software**.

Cada dia possui desafios progressivos, começando pelos fundamentos da linguagem e avançando até conceitos utilizados no desenvolvimento de aplicações reais.

---

## 🎯 Objetivos

* 🐍 Dominar os fundamentos de Python
* 🧠 Desenvolver lógica e raciocínio computacional
* 💻 Resolver problemas utilizando Python
* 🏗️ Aprender boas práticas de programação
* 🗄️ Trabalhar com bancos de dados
* 🌐 Desenvolver e consumir APIs
* 🧪 Aprender testes automatizados
* ⚡ Explorar recursos avançados da linguagem
* 🚀 Desenvolver projetos reais
* 📈 Documentar minha evolução como desenvolvedor
