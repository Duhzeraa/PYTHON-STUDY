# 🐍 PYTHON-STUDY

Repositório dedicado à prática diária de Python, organizado em uma trilha progressiva do básico ao desenvolvimento de aplicações reais.

## Estrutura

- `01-FUNDAMENTOS` — conceitos essenciais
- `02-INTERMEDIARIO` — recursos intermediários
- `03-AVANCADO` — recursos avançados
- `04-DESENVOLVIMENTO` — aplicações, APIs, banco de dados e projetos

Cada dia possui duas atividades:
- `atividade-01.py` — fixação
- `atividade-02.py` — desafio
